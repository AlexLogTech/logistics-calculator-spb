# 🚚 Logistics & Idle Time Calculator (СПб и Ленобласть)

Автономное PWA-приложение для логистов, снабженцев и транспортных компаний, работающих по Санкт-Петербургу и Ленинградской области. 

Позволяет за несколько секунд рассчитать полную стоимость рейса с учетом плеча доставки, специфики районов СПб и простоя на объекте.

---

## ✨ Основные возможности

- **Расчет стоимости рейса по СПб и ЛО:** автоматический подбор базового тарифа по километражу.
- **Учет специфики районов Санкт-Петербурга:** 
  - Готовые варианты надбавок для сложных зон (Центральный/Адмиралтейский/Василеостровский/Петроградский р-ны, КАД Север, Курортный р-н).
- **Модуль расчета простоя (1С):** 
  - Удобный ввод времени прибытия и убытия.
  - Автоматический перевод минут простоя в коэффициенты для 1С ($60\text{ мин} = 1.0$, $50\text{ мин} = 0.83$).
  - Авторасчет суммы доплаты сверх нормативного часа (1500 руб/час).
- **Гибкий редактор тарифов:** 
  - Базово зашиты тарифы доставки по СПб и ЛО.
  - Любой пользователь или компания может легко отредактировать сетку цен, список районов и свои надбавки прямо из интерфейса (сохраняется в памяти устройства).
- **Генератор отчетов:** автоматическое формирование готового текста детализации для отправки клиенту или дилеру в мессенджеры в 1 клик.
- **PWA / Mobile-First:** работает как на ПК, так и на смартфонах (iOS/Android), не требует интернета и устанавливается на главный экран как обычное приложение.

---

## 🛠 Технологический стек

- **Frontend:** HTML5, CSS3 (Modern Slate / Dark Mode), JavaScript (ES6+)
- **Storage:** LocalStorage API (для сохранения пользовательских тарифов)
- **Deployment:** GitHub Pages / Netlify

---

## 📱 Как использовать

1. Откройте приложение и укажите расстояние перевозки (км).
2. Выберите район доставки (при необходимости надбавки).
3. Укажите часы и минуты прибытия / окончания разгрузки.
4. Нажмите **«Скопировать текст»** и отправьте готовый расчет заказчику или дилеру.
